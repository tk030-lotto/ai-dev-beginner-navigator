# AI開発初心者お助けナビ

## AI Dev Beginner Navigator

> **「専門用語を知らなくても、困りごとから解決策とAIへの聞き方にたどり着ける」**

AIを使った開発で初心者が遭遇する、

* 「何がわからないのかわからない」
* 「エラーが出たけど、何を聞けばいいかわからない」
* 「AIに聞いたけど説明が難しくて先へ進めない」
* 「AIから言われたコマンドを実行して大丈夫なのかわからない」

といった問題を、**初心者の言葉から逆引きして解決へ導くブラウザ型ナビゲーションツール**です。

単なる30個のツール集ではなく、**「困りごと → 技術概念 → 解決方法 → AIへの質問」**を一本の流れとして提供します。

---

## コンセプト

AI開発では、技術知識そのものよりも、

> **「自分が何に困っているのかを技術的な言葉に変換できない」**

ことが初心者の大きな障壁になります。

本プロジェクトでは、専門用語を知らなくても、

* 「GitHubに載せたい」
* 「ファイルが消えた」
* 「赤い文字がいっぱい出た」
* 「AIにどう頼めばいい？」
* 「このコマンドを実行して大丈夫？」
* 「AIの答えが難しくてわからない」

といった自然な言葉から検索できます。

検索結果では、

1. まず何が起きているのか
2. 何を確認すればよいのか
3. 具体的にどう対処するのか
4. AIに相談する場合はどう質問するのか
5. やってはいけないことは何か

を順番に提示します。

## 主な特徴

### 1. 完全ブラウザ完結

* アカウント登録不要
* 専用サーバー不要
* AI APIキー不要
* 基本機能はローカルで動作
* ユーザーの入力や履歴を外部サーバーへ送信しない

ブラウザ上で完結するため、初心者でもすぐ利用できます。

### 2. 初心者の言葉から検索

専門用語だけでなく、初心者が実際に使う表現を検索対象とします。

例：

| 初心者の言葉       | 関連する概念               |
| ------------ | -------------------- |
| GitHubに載せたい  | push / publish       |
| 消えたファイルを戻したい | restore / reset      |
| 赤い文字が出た      | error / exception    |
| AIにどう頼めばいい？  | prompt / instruction |

### 3. プラグイン方式

Coreと知識コンテンツを分離します。

Coreは、

* プラグイン管理
* 検索
* 表示
* 履歴管理
* 画面遷移

を担当します。

具体的な初心者向け知識はPlugin側に持たせます。

そのため、将来的にプラグインを追加してもCoreの基本構造を変更する必要がありません。

### 4. AIへの質問文を生成

各問題に応じて、ユーザーの状況を差し込んだAI向け質問文を生成します。

生成した文章は、

* クリップボードへコピー
* 対応するAIのWebサービスを開く

という形で利用できます。

**AI APIを直接利用する方式ではありません。**

### 5. 学習履歴

ブラウザ内に、

* 検索した内容
* 閲覧した問題
* 作成したAI質問

を保存できます。

履歴はユーザー自身のブラウザ内だけで管理します。

## 基本的な利用フロー

```text
困った
  ↓
自分の言葉で検索
  ↓
関連する問題を表示
  ↓
「まず知っておくこと」を読む
  ↓
解決手順を確認
  ↓
必要ならAIへの質問文を生成
  ↓
AIへ質問
  ↓
回答を確認して作業
```

## 開発方針

本プロジェクトでは、最初から過剰な機能を実装しません。

**Coreを安定させたうえで、Pluginを追加する方式**を基本とします。

初期30プラグインは、すべて同じインターフェースで実装します。

---

## 技術方針

* TypeScript
* モダンWebブラウザ
* クライアントサイド処理
* Web Storage / IndexedDB
* プラグイン指向アーキテクチャ
* 外部AI API非依存
* 将来的なPWA対応を考慮

---

## プライバシー

ユーザーの検索内容や履歴は、原則としてブラウザ内に保存します。

外部AIへ送信する場合も、ユーザーが明示的に操作した場合のみWeb版AIへ渡す設計とします。

APIキー、秘密鍵、個人情報などの秘匿情報については、プロンプト生成・履歴保存時に可能な範囲で検出・マスクします。
